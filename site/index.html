    Three keys, no app switching.

    Clipmorph lives in the menu bar. Its panel floats over the window you’re in, so your cursor never leaves it.

    ⌘ C

    Copy

    Any text, in any app: an email, a chat message, a rough note.

    ⌥ Space

    Pick a recipe

    The panel opens without taking focus. Press a number key.

    ⏎

    Paste

    The result streams in, lands on your clipboard and can paste itself back.

    Built like a system utility.

    Your key, your model

    Works with Claude or OpenAI, with any model ID. Your key stays in the macOS Keychain, and requests go straight from your Mac to the provider.

    Keeps itself up to date

    Checks for new versions once a day and installs them only if they match GitHub’s checksum and the same developer signature. You can turn this off in Settings.

    Replies from your own documents

    Add product sheets, prices and tone-of-voice guides in Settings › Repository. “Reply from my repository” answers emails using only those facts, and marks anything they don’t cover with [to confirm: …].

    Copied text can’t give orders

    Your clipboard is sent as text to rewrite. Instructions hidden inside it are ignored.

    Ten recipes are built in, one per number key. Add your own in recipes.json (Settings › Open Recipes File). Add "usesRepository": true to let a recipe read your documents.

    [{
  "id": "commit-message",
  "name": "Commit message",
  "icon": "arrow.triangle.branch",
  "prompt": "Write a conventional git commit message for this diff."
}]

    Questions

    What does it cost?

    Clipmorph itself is free. Rewrites use your own Claude or OpenAI API key, so your provider bills you directly for what you use, at their normal rates. There’s no subscription and no account.

    Which models does it use?

    Claude (claude-opus-5-5 by default) or OpenAI (gpt-5 by default). You can type any other model ID from either provider in Settings.

    What happens to the text I copy?

    Clipmorph reads the clipboard when you open the panel and sends it to your chosen provider only when you run a recipe. It keeps no history and writes nothing you copy to disk. Documents in your repository stay in a folder on your Mac and are sent to your provider only when you run a recipe that uses them.

    Why does it ask for Accessibility access?

    Only for auto-paste, which types the result back into the app you were using. It’s off by default. Without it, results are still copied to your clipboard.

    macOS says it can’t verify the app. Is that normal?

    Yes. Clipmorph isn’t notarized by Apple yet, so the first launch is blocked. Open System Settings › Privacy & Security and click Open Anyway, or see the Terminal command in Download. After that it opens normally. The source is public on GitHub if you want to check what it does.

    How do updates work?

    From version 0.1.1, Clipmorph checks for updates once a day and installs them for you, or you can pick Check for Updates… in the menu bar. If you have 0.1.0, download the new version once by hand and replace the app in Applications. If you use auto-paste, switch Clipmorph back on under Privacy & Security › Accessibility afterwards.

    How do I uninstall it?

    Remove your API key in Settings, quit Clipmorph from the menu bar and move the app to the Trash. Custom recipes live in ~/Library/Application Support/Clipmorph.

    1. Unzip and move it to Applications

      Double-click Clipmorph.zip, then drag Clipmorph into your Applications folder.

    2. Allow it the first time

      Clipmorph isn’t notarized by Apple yet, so macOS blocks the first launch. Open System Settings › Privacy & Security, scroll down and click Open Anyway. Or run this once in Terminal:

      xattr -dr com.apple.quarantine /Applications/Clipmorph.app

    3. Add your API key

      Settings opens on first launch. Paste a Claude or OpenAI key, then press ⌥ Space anywhere.

    Prefer to build it yourself?

    The full source is on GitHub. You only need the Swift Command Line Tools.

cd Clipmorph && ./scripts/build-app.sh
open build/Clipmorph.app
